## 功能（概览）

- ① 自动搜索：城市（杭州/深圳可多选）× 关键词组合，抓取并去重岗位
- 规则筛选 + 优先级排序（排除词/加分词在 `auto.js` 顶部常量，可在代码里改）
- ③ 抓详情：真实薪资、经验/学历、公司规模/融资、JD 全文
- ⑤ 智能打分（可选）：需本地运行 Node 服务 + 你自己的 DeepSeek API Key（见下）
- ② 批量打招呼：每日上限、可暂停、**跨天防重复**（打过的不再打）
- ④ 生成日报：网页表格新标签查看，另存 MD/JSON
- 记录存在浏览器本地（`chrome.storage`），数据不出本机

## 安装（本地加载）

1. 打开 `chrome://extensions` → 打开「开发者模式」
2. 点「加载已解压的扩展程序」→ 选择本目录 `extension/`
3. 平时用你的 Chrome 打开并登录 BOSS，点扩展图标 →「打开自动投递助手」

## 智能打分（可选，需本机跑服务）

```bash
cd 项目根目录
echo 'DEEPSEEK_API_KEY=你的key' > .env   # 不入 Git
npm ci
npm run score:serve   # 启动后显示 http://127.0.0.1:8799（只监听本机）
```

- 扩展里勾选「抓详情后自动打分」即可；服务没开会明确提示，不影响其他功能。
- 打分用你提供的画像（仓库示例为假人，请在 `config/profile.yaml`/代码中改为自己的画像）。

## 自行配置项

| 配置 | 位置 |
|---|---|
| 城市/关键词/每日上限/打招呼话术/自动打分 | 扩展「自动投递助手」页面顶部 |
| 排除词 / 加分关键词 / 打招呼入口文案 | `extension/auto.js` 顶部常量（后续版本会做成设置页） |
| 打分用候选人画像 | 项目根 `config/candidate.json`（示例：`config/candidate.example.json`） |
| DeepSeek API Key | 项目根 `.env`（服务端读取） |
