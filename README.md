# BOSS 岗位助手（Job Agent）

一个帮你**找 BOSS 直聘岗位**的 Chrome 扩展：自动搜索 → 筛选 → 抓详情 → （可选）AI 打分 → 帮你批量打招呼 → 每天生成一张清晰的工作日报。

> 使用自动化功能有平台风险，请自行判断。

---

## 一、这是什么

把你的求职日常里"最重复的几步"变成一键：

| 本来你要做 | 用了它之后 |
|---|---|
| 手动搜"杭州+深圳 AI产品经理/Agent产品经理" | 一次勾选，自动帮你搜 |
| 一个个点开看 JD、记薪资 | 批量抓详情：真实薪资 / 经验学历 / 公司规模 / JD 全文 |
| 纠结"这个岗位值不值得打招呼" | 可选：AI 给你打分和建议（如 `86分·优先打招呼`） |
| 复制粘贴话术、挨个发 | 一键批量打招呼（每日上限、防重复、随时暂停） |
| 手写表格汇报今天看了什么 | 一键生成网页版日报（新标签打开） |

---

## 二、功能清单（当前版本 v0.3）

**基础功能（装完就能用，不需要任何额外配置）**
- 自动搜索：多城市 × 多关键词，自动合并去重
- 规则筛选与排序：排除"销售/标注/驻外"等，AI 相关岗位排前面
- 抓取岗位详情：薪资（真实数字）、经验/学历、公司规模/融资、JD 全文
- 批量打招呼：每日上限（默认 5，可调 1–10）、可暂停、**同岗位永远不重复打**
- 一键日报：网页表格查看 + 导出 MD/JSON 存档

**可选 AI 功能（需要你自己准备一个 DeepSeek API Key）**
- 智能打分：读 JD 后给每个岗位打分和建议理由
- 打分只在你的电脑本地进行，岗位数据不会上传给任何第三方（除你选的 DeepSeek 接口本身）

## 三、开始使用（步骤）

### 第 0 步：确认环境
- 电脑上装有 **Google Chrome**
- （仅 AI 打分需要）装了 **Node.js 18+**（建议 20+），并有一个 [DeepSeek API Key](https://platform.deepseek.com/)

### 第 1 步：安装扩展
1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角「**开发者模式**」
3. 点「**加载已解压的扩展程序**」，选择本仓库里的 `extension` 文件夹
4. 浏览器右上角出现「BOSS 岗位助手」图标 → 完成

### 第 2 步：打开 BOSS 并登录（你自己操作）
- 用你的 Chrome 打开 `www.zhipin.com`，正常扫码登录
- 登录后保持浏览器开着（别关窗口）

### 第 3 步：跑第一次
1. 点扩展图标 →「打开自动投递助手」（会开一个新页面）
2. 在助手页选：城市（杭州/深圳）、关键词、每日上限
3. 点「**① 开始搜索与筛选**」→ 自动搜索并出表格
4. 勾选想打招呼的岗位 → 点「**② 对选中岗位打招呼**」
5. 点「**④ 生成今日日报**」→ 自动弹出网页表格

> 首次使用强烈建议：每日上限先设 **1**，跑通一次看效果再调大。

### 第 4 步（可选）：开启 AI 打分
```bash
cd 项目目录
npm ci                      # 只第一次需要
echo 'DEEPSEEK_API_KEY=你的key' > .env
npm run score:serve         # 出现 "http://127.0.0.1:8799" 即成功，保持这个终端开着
```
然后回到扩展助手页：
- 确认「**抓详情后自动打分**」已勾选
- 点「**③ 抓勾选岗位详情**」→ 详情列会自动出现 `模型分/建议`

## 四、常见问题

| 问题 | 回答 |
|---|---|
| 需要安装什么？ | 只装扩展就能用基础功能；AI 打分再额外装 Node.js |
| AI 打分安全吗？ | 打分在本机服务里做，只调用 DeepSeek 接口，Key 存在你本地|
| 会不会重复打同一岗位？ | 不会。打过的岗位会记在浏览器本地，永远自动跳过 |
| 每天最多打几个？ | 默认 5，助手页可调 1–10；到上限自动停，第二天重置 |
| 遇到验证码/页面异常？ | 会停下并停在当前页面等你人工处理，绝不硬闯 |
| 我改了代码怎么生效？ | `chrome://extensions` 里点该扩展的「刷新」即可 |
